# Object-Oriented Design Patterns

This directory contains various implementations of object-oriented (OO) design patterns, as well as simulations of these patterns using a procedural-parametric approach. It is perhaps inaccurate to label these simulations as "patterns" proper; in procedural-parametric programming, it is often simpler to implement direct, ad-hoc solutions, as this paradigm offers greater flexibility in code construction. Several variations of programs implementing the same design patterns are provided—a choice driven by purely subjective factors.

## fig-patterns

The [fig-patterns](fig-patterns) subdirectory contains demonstrations of design patterns and their simulations, using geometric shapes as examples. In essence, this is a continuation of the work with shapes—the same examples used to illustrate "evolutionary expansion" in the corresponding section.

## shvets-patterns

This subdirectory contains procedural-parametric simulations of the OO design patterns featured on Alexander Shvets’ website, [Refactoring.Guru](https://refactoring.guru/ru/design-patterns/cpp), which provides source code examples in C++. This serves as a straightforward method for demonstrating how patterns can be simulated based on existing C++ source code. The examples are organized by programming language and paradigm within the [shvets-patterns](shvets-patterns) subdirectory.

## animals-patterns

The [animals-patterns](animals-patterns) subdirectory contains OO implementations of design patterns that use animals—and other entities—as illustrative examples. These, along with their procedural-parametric imitations, serve as examples illustrating the comparison between the object-oriented (OO) and procedural-parametric (PP) paradigms—a topic explored in the text on my website: [The Procedural-Parametric Paradigm and OO Design Patterns](http://www.softcraft.ru/ppp/patterns/intro/).
